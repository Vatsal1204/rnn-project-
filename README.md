# 🧠 Emotion Detection AI

A Deep Learning based Emotion Detection Web App built using 
Simple RNN (TensorFlow/Keras) and deployed using Streamlit.

This project predicts human emotions from text input.

---

## 🚀 Demo

Enter a sentence like:

"I feel amazing today"

The model predicts the emotion with confidence score.

---

## 🛠 Tech Stack

- Python
- TensorFlow / Keras
- Simple RNN
- Scikit-learn
- Streamlit
- NumPy
- Pickle
